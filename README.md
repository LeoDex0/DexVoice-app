# DexVoice

![DexVoice](images/cover.jpg)

Голосовой ассистент Декс для Windows 10 и 11. Команды распознаются прямо на компьютере, без облака.

Что умеет:

- открывать и закрывать программы, сайты и папки голосом;
- громкость, музыка, видео, окна, скриншоты, выключение ПК;
- таймеры, будильники, напоминания, заметки, калькулятор, погода, курсы валют;
- диктовка текста в любое окно;
- больше 2300 готовых команд для Windows, браузеров, Telegram, Discord, Steam, OBS, Office и других программ;
- свои команды и цепочки команд;
- пульт с телефона по домашней Wi-Fi.

## Как установить

1. Откройте [Releases](../../releases) и скачайте последний `DexVoice-...-setup.exe`.
2. Запустите его и нажмите «Далее». Права администратора не нужны, папку можно выбрать.
3. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», потом «Выполнить в любом случае».

Без установки: скачайте `DexVoice-...-windows.zip`, распакуйте в любую папку и запустите `DexVoice.exe`.

При первом запуске откроется окно настройки: программа скачает модель распознавания речи (около 200 МБ,
нужен интернет), там же выбирается микрофон. Дальше распознавание работает без интернета.

Удалить: «Параметры», «Приложения», DexVoice.

## Пульт в Telegram

В DexVoice: Настройки, «Пульт через Telegram», включите и скопируйте ключ. В Telegram откройте
[@DexVoice_bot](https://t.me/DexVoice_bot), нажмите «Пульт» и введите ключ. Пульт работает откуда угодно:
тачпад, экран компьютера, плеер, громкость, команды. Боту можно писать команды и присылать голосовые.

Скажите «Декс» и команду, например: «Декс, открой ютуб».

## Пробный срок и ключ

Первые 7 дней всё работает бесплатно. Потом нужен ключ.

1. Откройте в программе раздел «Лицензия».
2. Нажмите «Скопировать» рядом с кодом ПК.
3. Отправьте этот код автору.
4. Вставьте полученный ключ и нажмите «Активировать».

Ключ работает на одном компьютере.

## Обновления

Раздел «Обновления», кнопка «Проверить обновления», потом «Обновить». Ваши настройки и команды
при обновлении сохраняются.

## Системные требования

- Windows 10 или 11, 64 бит
- 4 ГБ памяти (лучше 8 ГБ)
- микрофон
